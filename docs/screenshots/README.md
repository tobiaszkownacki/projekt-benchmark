# Screenshots

Taken from the running system on data from 194 computed runs
(`tools/local_backend/seed.py`). These are not mock-ups: every number in these
images came out of the project's own evaluator.

| File | What it shows |
|---|---|
| `01-overview.png` | Landing page: what the system is, counters, short ranking |
| `02-leaderboard.png` | Full ranking with filters, IQR and a swappable aggregate |
| `03-leaderboard-dark.png` | The same in dark mode |
| `04-runs.png` | Run list with lifecycle states and time spent queued |
| `05-run-detail.png` | Run page: metrics against budgets, metadata, state history, curve |
| `06-run-files.png` | Artifact browser, PNG preview, deep link to one file |
| `07-run-files-csv.png` | CSV rendered as a table |
| `07b-files-log.png` | `.out` log renderer |
| `08-run-failed.png` | Failed run — `error_message` shown, not hidden |
| `09-compare.png` | Comparison: median with IQR band, budget axis, difference table |
| `10-compare-dark.png` | The same in dark mode, on the gradient axis |
| `11-docs.png` | Optimizer contract with examples read from the code |
| `12-submit.png` | Submission form with the daily limit |
| `13-admin.png` | Admin: account approval, per-user budget consumption |
| `14-admin-queue.png` | RabbitMQ state, outbox, SLURM jobs, orphans |
